# OpenWeb

OpenWeb is a simple, open-source Android web browser built with Kotlin
and Android WebView.

## Features

- Browse websites inside the app
- Address bar and web search
- Back, forward, and reload controls
- Minimal Android interface

## Build

The APK is built using GitHub Actions.

1. Open the repository's Actions tab.
2. Select OpenWeb APK.
3. Select Run workflow.
4. Download the OpenWeb-debug-apk artifact.
